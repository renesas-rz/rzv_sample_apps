## Overview

This sample application combines [**YOLOv8-seg**](https://github.com/renesas-rz/sample_app_v2h_gpl/tree/main/app_yolov8_seg_cam) and [**StereoSGM**](https://github.com/renesas-rz/rzv_sample_apps/tree/main/S03_stereosgm) to enable simultaneous object detection, segmentation, and distance measurement. Using segmentation masks generated by YOLOv8-seg and stereo disparity data from StereoSGM, it provides fast and accurate distance estimation for each detected object.

## Build the application

1. Please refer to [Application Example for RZ/V2H](https://github.com/renesas-rz/rzv_drp-ai_tvm/blob/main/apps/build_appV2H.md#how-to-build-the-application).  An example of command execution is shown below.

    ```bash
    cd $TVM_ROOT/how-to/rzv_sample_apps/S04_app_yolov8_seg_stereo_cam/src
    cp $TVM_ROOT/how-to/sample_app_v2h/app_deeplabv3_cam/src/CMakeLists.txt CMakeLists.txt
    mkdir build
    cd build

    cmake -DCMAKE_TOOLCHAIN_FILE=$TVM_ROOT/apps/toolchain/runtime.cmake -DAPP_NAME=app_yolov8_seg_stereo_cam ..
    sed -i -e 's/INPUT_CAM_TYPE 0/INPUT_CAM_TYPE 0/g' ../define.h # when using USB cameras. (default)
    sed -i -e 's/INPUT_CAM_TYPE 0/INPUT_CAM_TYPE 1/g' ../define.h # when using e-CAM22 cameras.
    sed -i -e 's/INPUT_CAM_TYPE 0/INPUT_CAM_TYPE 2/g' ../define.h # when using e-CAM25 cameras.
    sed -i -e 's/INPUT_CAM_TYPE 0/INPUT_CAM_TYPE 3/g' ../define.h # when using file images.
    make
    ```

2. The `app_yolov8_seg_stereo_cam` application binary is generated.  

## AI models

Step 1: Follow the procedure titled [“How to Convert yolov8-seg_onnx Models for V2H”](https://github.com/renesas-rz/rzv_drp-ai_tvm/tree/main/docs/model_list/how_to_convert/How_to_convert_yolov8-seg_onnx_models.md) to create a trimmed ONNX model (yolov8*-seg_cut.onnx).

Step 2: Complete the following steps. This sample only uses [yolov8-seg](https://github.com/ultralytics/ultralytics).

<!-- This sample only uses [yolov8-seg](https://github.com/ultralytics/ultralytics).

```bash
cd $TVM_ROOT/tutorials
git checkout compile_onnx_model_quant.py
sed -i -e '/# Input shape helper/,/return \[batch_dim\] + \[int(d.get("dimValue")) for d in dim_info\[1::\]\]/d' compile_onnx_model_quant.py
sed -i -e 's/get_input_shape(model_file, inp)/opts["input_shape"]/g' compile_onnx_model_quant.py
sed -i -e 's/0.485, 0.456, 0.406/0.0, 0.0, 0.0/g' compile_onnx_model_quant.py
sed -i -e 's/0.229, 0.224, 0.225/1.0, 1.0, 1.0/g' compile_onnx_model_quant.py
sed -i -e 's/256/640/g' compile_onnx_model_quant.py
sed -i -e 's/ 224/ 640/g' compile_onnx_model_quant.py
sed -i -e '/ref_result_output_dir =/,/exist_ok=True)/d' compile_onnx_model_quant.py
sed -i -e '/flatten().tofile(/d' compile_onnx_model_quant.py
sed -i -e '/os.path.join(ref_result_output_dir, "input_"/d' compile_onnx_model_quant.py
sed -i -e 's/ref_result_output_dir/output_dir/g' compile_onnx_model_quant.py
sed -i -e 's/_fp32//g' compile_onnx_model_quant.py 
sed -i -e 's/_fp16//g' compile_onnx_model_quant.py
sed -i -e 's/FORMAT.BGR/FORMAT.YUYV_422/g' compile_onnx_model_quant.py
sed -i -e 's/480, 640, 3/640, 640, 2/g' compile_onnx_model_quant.py # when using USB camera and e-CAM22 (image size 640 x 480)
```

### Additional edit for e-CAM25 camera (image size 1280 x 720)

## Execution Mode

The sample software starts in one of the following modes depending on the arguments entered at startup.

```text
1. Default parameter mode
2. Simple parameter mode
3. Detail parameter mode
```

### 1. Default parameter mode

When starting the sample software, enter only \<**mode**\> as the argument. In this case, the parameter table is set to `Item_Num = 25`, and stereo computation is executed by either OCA or CPU depending on the value of \<**mode**\>.<br>

With regard to Meaning of parameters refer to Simple and Detail parameter mode.

```sh
./app_yolov8_seg_stereo_cam <Mode>

    For example:
    ./app_yolov8_seg_stereo_cam oca
    ./app_yolov8_seg_stereo_cam cpu
```

- The mode parameter specifies whether Stereo processing is executed on OCA or the CPU.

  | Mode |
  | :-: |
  | oca |
  | cpu |

  If the \<**Mode**\> is omitted, OCA is selected by default.<br>

  ```sh
  ./app_yolov8_seg_stereo_cam
  ```

### 2. Simple parameter mode

Select "mode" and "Item_Num" from a combination of execute mode, Stereo Calculate Size, and Stereo Parameter.
With regard to Meaning of parameters refer to Detail parameter mode. 

```sh
./app_yolov8_seg_stereo_cam <Mode> <Item_Num>

    For example:
    ./app_yolov8_seg_stereo_cam oca 25
    ./app_yolov8_seg_stereo_cam cpu 25
    ./app_yolov8_seg_stereo_cam oca 0
    ./app_yolov8_seg_stereo_cam oca 35
```

- The mode parameter specifies whether Stereo processing is executed on OCA or the CPU.

  | Mode |
  | :-: |
  | oca |
  | cpu |

- The Item_Num parameter configures the stereo processing settings as shown in the table below.<br>

  - For higher processing speed, select Item_Num values from 30 to 39, which use smaller stereo calculation sizes.<br>
     For higher disparity image resolution, select Item_Num values from 0 to 9, which use larger stereo calculation sizes.<br>

    | Item_Num |Processing<br> Speed|Disparity image<br> resolusion| 
    | :-: | :-: | :-: |
    | 0~9 |low|high|
    | 10~19 |↓|↑|
    | 20~29 |↓|↑|
    | 30~39 |high|low|

  - The disparity range increases according to the last digit of Item_Num in the following order: 0–3, 4–7.

    | The last digit of<br> Item_Num |Disparity| 
    | :-: | :-: |
    | 0 , 4 | small |

### 3. Detail parameter mode

Run the following command with the parameter below.

```sh
./app_yolov8_seg_stereo_cam <Mode> <Stereo Cal Width> <Stereo Cal height> <P1> <P2> <Disparity> <Win-X> <Win-Y> <uniquenessRatio> <HeatMap> <focus_en> <cam_tran_cnt_max> <tx> <ty> <angle> <wait> 

    For example:
    ./app_yolov8_seg_stereo_cam  oca 320 240 10 30 64 9 9 0 20 1 100 0 0   0 0
    ./app_yolov8_seg_stereo_cam  cpu 320 240 10 30 64 9 9 0 20 1 100 0 0   0 0
    ./app_yolov8_seg_stereo_cam  oca 320 240 10 30 64 9 9 0 20 0   0 0 5.5 0 0
```

- The mode parameter specifies whether Stereo processing is executed on OCA or the CPU.

  | Mode |
  | :-: |
  | oca |
  | cpu |

- Stereo Cal Width and Stereo Cal Height specify the image width and height used for Stereo processing.

  | Stereo Calculate<br />Width | Stereo Calculate<br />Height |
  | :-: | :-: |
  | 640 | 480<sup><a href="#note2">[2]</a></sup><br />360<sup><a href="#note3">[3]</a></sup> |
  | 480 | 360<sup><a href="#note2">[2]</a></sup><br />272<sup><a href="#note3">[3]</a></sup> |
  | 320 | 240<sup><a href="#note2">[2]</a></sup><br />180<sup><a href="#note3">[3]</a></sup> |
  | 240 | 180<sup><a href="#note2">[2]</a></sup><br />136<sup><a href="#note3">[3]</a></sup> |

- P1 and P2 are smoothing parameters for the disparity calculated by Stereo processing.

  | p1 | p2 | |
  | :-: | :-: | :-: |
  | 2 \~ 80 | 5 \~ 80 | Stereo Cal Width <= 640 |
  | 2 \~ 50 | 5 \~ 50 | Stereo Cal Width <= 1280 |

  Note: P1 must be less than P2.

- Disparity specifies the search range for matching patterns between the left and right images in Stereo processing.

  | Disparity | |
  | :-: | :-: |
  | 16 \~ 256 | Stereo Cal Width <= 1280 |
  
  Note: Disparity must be a multiple of 4.

- Win_x and Win_y are parameters that specify the window size used for matching between the left and right images.

  | Win_x |
  | :-: |
  | 3,5,7,9 |

  | Win_y |
  | :-: |
  | 3,5,7,9 |
  
  Note: win_x = win_y

  <img src=./img/census_flow.png width=300 alt="Census flow" style="border: 3px solid grey;">

- UniquenessRatio is a parameter used to determine the reliability of matching between the left and right images.<br>
  It defines the threshold ratio between the best (minimum) cost value and the second-best cost value.<br>
  If the difference exceeds the threshold, the disparity value is returned; otherwise, 0 is returned.

  | uniquenessRatio |
  | :-: |
  | 0\~100 |

- HeatMap specifies the color map index used by cv::applyColorMap().

  | HeatMap ||
  | :-: | :-- |
  | 0 \~ 21 |Item_Num values 2, 4, and 9 are not supported.<br> Item_Num 20 is supported only when the stereo processing size is 320 × 240 or smaller.|

  <img src=./img/heat_map_color.png width=250 alt="heatmap" style="border: 3px solid grey;">

- Focus_en, cam_tran_cnt_max, tx, ty, and angle are parameters used to shift and rotate the right image position during Stereo matching.

  | focus_en | |
  | :-: | :-: |
  | 0 | Manual Adjustment |
  | 1 | Auto Adjustment |

  | cam_tran_cnt_max | |
  | :-: | :-: |
  | 0 \~ 300 | Maximum Number of Auto Adjustments |

  | tx | ty | angle |
  | :-: | :-: | :-: |
  | ±50 |±50|±10|

- The wait parameter is used to enable or disable synchronization between "the camera image" and "AI inference and Stereo processing results".

  | wait | |
  | :-: | :-: |
  | 0 | disable synchronization |
  | 1 | enable synchronization |

## Tuning the image position

- Auto Adjustment (focus_en = 1)<br>

  Automatically searches for and sets the vertical offset of the right image that minimizes noise in the disparity image.<br>

  The right image is shifted vertically (y++) up to the specified maximum offset (cam_tran_cnt_max), and the noise level is evaluated at each y position. The offset with the lowest noise level is selected and used as the correction value.
  During the adjustment process, the current vertical offset (y) and iteration count (F) are displayed in the Heat Map of Disparity. Once the adjustment is complete, "Done" is displayed for F.

  <img src=./img/auto_adjustment.png width=700 alt="auto_adjustment" style="border: 3px solid gey;">  

  In addition, the vertical offset can be fine-tuned manually using the keyboard after the automatic calibration is completed.
  To perform manual adjustment after automatic calibration, launch the application with terminal log output suppressed by using the following command:

  ```sh
  ./app_yolov8_seg_stereo_cam > /dev/null 2>&1
  ```

- Manual Adjustment (focus_en = 0)<br>

  During software operation, the right image can be translated vertically and rotated using keyboard input, allowing fine adjustment of the image alignment.<br>
  Enter the following command to disable terminal log output.

  ```sh
  ./app_yolov8_seg_stereo_cam > /dev/null 2>&1
  ```

  ```text
  Press ENTER to quit.

  Press "w" and ENTER key to move the image up.
  Press "x" and ENTER key to move the image down.
  Press "s" and ENTER key to rotate the image clockwise.
  Press "a" and ENTER key to rotate the image counterclockwise.
  ```

```sh
cp camera_EC25_left_YUYV_1280_720.csv /home/weston/sample_yolov8_seg_stereo_cam/calib_data
cp dist_EC25_left_YUYV_1280_720.csv /home/weston/sample_yolov8_seg_stereo_cam/calib_data

```

If you use these calibration data, **modify define.h** as shown below and rebuild the application.

Because camera calibration results can vary, using the same calibration file for both the left and right cameras may provide better results in some cases.

```txt

    #define CAM_LEFT_CALIB   "calib_data/camera_EC25_left_YUYV_1280_720.csv";
    #define CAM_RIGHT_CALIB  CAM_LEFT_CALIB

    #define CAM_RIGHT_DIST   CAM_LEFT_DIST
    //#define CAM_RIGHT_DIST   "calib_data/dist_EC25_right_YUYV_1280_720.csv";

In case of using 4 calibration files

    #define CAM_LEFT_CALIB   "calib_data/camera_EC25_left_YUYV_1280_720.csv";
    //#define CAM_RIGHT_CALIB  CAM_LEFT_CALIB
```
